# Fonts

`TwemojiCountryFlags.woff2`: the country-flag emoji only, so flags show on Windows,
whose own emoji font has none (it shows the two letters, "FR", instead). A subset of
Twemoji Mozilla made by TalkJS for `country-flag-emoji-polyfill` (v0.1.10).
